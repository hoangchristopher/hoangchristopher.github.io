As for the homographies, we will solve for them using this system of equations where a point (x, y) on the "before" image corresponds to a point (u, v) on the "after" image. The resulting vector, when reshaped to 3x3 with the element in the 3rd row and 3rd column equalling a constant scaling factor, will give us our 3x3 homography matrix.

A.4: Blend the Images into a Mosaic"

To blend two images together, I first computed the homography required to warp the correspondances from the first image to the second image. Then, I used this homography to warp the first image. From there, I created a mask that follows the new shape of the warped first image, and then used a Laplacian pyramid to blend the warped first image and the second image.

B.4: RANSAC for Robust Homography

Previously, we used hand-plotted correspondances to calculate an appropriate homography matrix for our image warping. However, hand-plotted correspondances are subject to human error that can lead to pixels being incorrectly assigned from one image to another. Thus, we would rather use an algorithm to determine what homography matrix we should use.

The algorithm of choice is Random Sample Consensus (RANSAC), which essentially grabs 4 feature pairs between the two images, calculates the homography based off of those 4 reference points, and then applies said homography to the respective image. From there, the algorithm inspects the rest of the image and sees how many points line up correctly (meaning the difference in the expected point and the point after transformation by the homography matrix are less than a value epsilon). If a point lines up correctly, we can add it to a "score" for the current homography matrix while keeping all the good inliers. Repeat this process until we are satisfied. After our desired iterations, we take the set of inliers from the homography matrix that resulted in the highest amount of correct matches and then recompute the homography matrix on those inliers. This will return a much more accurate homorgraphy matrix, which we will then use to warp our images and construct a mosaic.
